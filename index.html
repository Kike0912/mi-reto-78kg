Atajos de Apple

Puedes crear un atajo que abra una sección o precargue un peso para que confirmes el registro.

Para registrar desde Atajos: solicita un número, construye el enlace con ?pantalla=peso&peso=VALOR y usa “Abrir URL”. La aplicación rellenará el campo, pero siempre tendrás que confirmar el guardado.

Notificaciones y privacidad

Los avisos web en iPhone requieren iOS/iPadOS 16.4 o posterior, instalación en pantalla de inicio y un servidor Web Push. Esta versión no tiene servidor de notificaciones; por eso no solicita permisos que no puede utilizar. Apple Calendar es el recordatorio disponible sin servidor.

Apple Salud y Apple Watch requieren una aplicación nativa con HealthKit. Esta PWA no accede directamente a esos datos.

Sonidos y vibración

Los datos principales se guardan localmente en este dispositivo. Exporta respaldos con regularidad y guárdalos en Archivos o iCloud Drive.
